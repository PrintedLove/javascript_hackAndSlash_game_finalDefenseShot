자바스크립트 Canvas API를 활용한 핵 앤 슬래시 액션 탄막 게임, Final Defense Shot(최후방어사격) 프로젝트입니다. 그래픽 리소스를 일절 사용하지 않아 해당 소스코드로만 동작이 가능합니다. 이전 프로젝트인 Seven Criminals의 코드를 재활용했습니다.

Eclipse Public License - v 2.0가 사용되었습니다.

플레이 하는법-

게임 시작, 일시 정지, 재시작: Enter

플레이어 이동 : A, W, D, S or ◀▲▶▼ (방향키)

마우스 방향으로 자동공격.

레벨 업 마다 업그레이드 선택.

------------------------------------------

"Final Defense Shot" is hack & slash action game using JavaScript canvas API. Since no graphic resources are used, it can only be operated with this source code. Reused code from my previous project, Seven Criminals.

Eclipse Public License - v 2.0 is used.

How to play-

Start, Pause, Restart: Enter

Player Move : A, W, D, S or ◀▲▶▼ (arrow keys)

Auto-attack in the direction of the mouse.

Upgrade selection at each level up.
